Connect GitHub Authentication

To enable seamless 1-click GitHub Sign-In for everyone on your domain, register a free GitHub OAuth application. (Takes 30 seconds)

Step 1 of 2

Register OAuth Application on GitHub

Click the button below to open GitHub's OAuth registration page. Fill in these two URLs:

HOMEPAGE URL:
https://zerohost-platform.onrender.com
AUTHORIZATION CALLBACK URL:
https://zerohost-platform.onrender.com/api/auth/github/callback
🐙 Open GitHub OAuth Registration Page ↗
Step 2 of 2

Paste Client ID & Client Secret

Once created on GitHub, paste the generated credentials below to immediately activate GitHub login.

💡 Permanent Render Setup: To persist your credentials permanently across restarts, also add them to your Render Dashboard → zerohost-platform → Environment as GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET.
