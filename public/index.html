How ZeroHost Works Under the Hood

A dual-repository zero-cost architecture designed for maximum privacy, speed, and zero bills.

🔒 1. Private Source Repository

Your original templates, readable CSS/JS code, private API keys, and environment variables stay in a strictly private GitHub repository. Nobody on the internet can see your source code.

⚙️ 2. Automated GitHub Actions Build

Whenever you edit a file or deploy, GitHub Actions automatically minifies your HTML, compresses styles, mangles JS variable names, and copies production-ready files to your public gateway repository.

🌍 3. Dual Public Gateway & Global CDN

Web pages are served seamlessly through GitHub Pages (`.github.io//`), while heavy assets (JS, CSS, images) are served globally via jsDelivr CDN (`cdn.jsdelivr.net`).

⚡ 4. Free Serverless Compute

For Node.js and dynamic backends, Cloudflare Workers provides 100,000 requests per day for free, talking to your private GitHub repo as a database without needing expensive cloud databases.

Getting Started with ZeroHost

Everything you need to know to launch static websites, software download portals, or APIs with $0 hosting costs.

🚀 1. Deploying in 60 Seconds (No Git Required)

ZeroHost was built specifically so non-technical creators never have to struggle with command-line tools, SSH keys, or terminal commands.

Quick Flow: Go to New Deployment → Choose a starter template → Name your project → Click Launch My Website Now.

Behind the scenes, ZeroHost talks to GitHub's REST API, generates two linked repositories, configures GitHub Actions continuous deployment, injects your deployment tokens, and turns on global CDN edge distribution automatically.

⚡ 2. Run Files vs. Storage Files (The Core Architecture)

To eliminate expensive bandwidth fees, ZeroHost cleanly divides your project into two folders inside the Site File Manager:

Project Root Structure: ├── src/ <-- ⚡ RUN FILES (HTML, CSS, JavaScript) │ ├── index.html (Served via GitHub Pages with edge caching) │ ├── css/style.css │ └── js/main.js └── assets/ <-- 📦 STORAGE ASSETS (Installers, 4K Images, Videos) ├── Velocity_Setup.exe (Streamed worldwide via jsDelivr CDN at multi-gigabit speeds) ├── Extension.zip ($0 bandwidth fees regardless of millions of downloads) └── screenshots/

You can edit files directly in your browser with our built-in In-Browser Web Studio. When you hit Save & Deploy, your changes are automatically committed to your private repository and synced to the global edge.

📦 3. Software Distribution & Heavy Downloads (Velocity Blueprint)

If you're distributing desktop apps, games, or media (like Velocity Download Manager with 48MB installers):

  • Upload your .exe, .zip, or .dmg file into the assets/ folder via the drag & drop zone.
  • The File Manager immediately generates an ultra-fast jsDelivr Global CDN URL.
  • Click 📋 Copy Link and paste it directly into your website's download button.
  • Even if 50,000 users download your 50MB file (2.5 TB of traffic), your bill is $0.00.

🌐 4. Custom Domains & Free Automatic SSL

Every deployment receives a free https://<username>.github.io/<repo>/ URL. To connect your own custom domain (e.g. www.mycoolapp.com):

DNS Setup for Custom Domains: 1. In your domain registrar (GoDaddy, Namecheap, Cloudflare): - Add a CNAME record: Name = "www", Value = "<your-username>.github.io" 2. In ZeroHost File Manager: - Create a file named "CNAME" in the root with your domain: "www.mycoolapp.com" 3. GitHub automatically provisions a Let's Encrypt SSL certificate for free.

Vercel's free tier has a 4.5 MB request body limit and a 100 GB monthly bandwidth limit. If you distribute software installers or host media, you will exceed this in days. On Vercel Pro, bandwidth overage is $40 per 100 GB. A viral launch can easily hit you with a surprise $1,000+ bill.

⚠️ The Hostinger Renewal Price Hike

Shared hosts like Hostinger advertise low intro prices like $2.99 or $3.99/mo, but lock you into 4-year upfront commitments. When renewal hits, prices jump by 300% to 400% ($12 to $16/mo), and your site is throttled by strict CPU and inode limits.
